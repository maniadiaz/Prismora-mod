# Preparación de publicación — 0.1.0

## Artefactos

- Archivo principal: `prismora-0.1.0.jar`.
- Bundle: `Prismora-0.1.0.zip`, con JAR, packs de ejemplo y documentación.
- Versionado: 0.1.0, primera entrega de postproceso; tratar como beta.
- Juego: Minecraft Java 26.3. Loader: Forge 66.1.0. Java: 25.
- Entorno: cliente obligatorio; servidor no requerido.
- Categoría sugerida: optimización gráfica / shaders / utilidades visuales según las categorías de la plataforma.
- Descripción y capturas: README.md, CHANGELOG.md y capturas reales de las pruebas; no anunciar sombras solares ni compatibilidad OptiFine/Iris.
- Licencia del código original: All Rights Reserved mientras el titular elige otra; conservar avisos del MDK.

## Estado

Esta entrega prepara archivos y pruebas locales; no crea páginas ni versiones públicas en Modrinth o CurseForge. Para publicarlos se necesitan acceso a las cuentas/proyectos de su titular, identificadores de proyecto, metadatos de esas plataformas y la decisión final del titular sobre licencia y presentación.

No hay credenciales de publicación en el repositorio. Las pruebas no dependen de servicios de publicación. Los enlaces de descarga públicos solo se documentarán cuando la publicación ocurra.
